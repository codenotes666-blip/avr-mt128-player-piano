Magnetic field module

KY-024

A linear Hall sensor plus an adjustable threshold comparator. It reports both magnetic-field strength/polarity as an analog voltage and a simple threshold state as a digital signal.

0149E / AH49E Hall element

Converts magnetic flux perpendicular to the sensor face into an analog voltage. With no applied field, output is typically near half the supply voltage.

→
02A0 analog output

Direct Hall-sensor voltage for measuring field changes and distinguishing magnetic pole direction relative to the module orientation.

↘
03LM393 comparator

Compares the Hall voltage with the threshold set by the blue potentiometer.

→
04D0 digital output

Changes logical state when the comparator threshold is crossed. Use this for simple magnet present/absent or position events.

Manufacturer orientation

Four-pin header

Sensor element at the top, connector at the bottom. Always confirm the silkscreen on clone modules before applying power.

A0
Analog output

Continuous Hall voltage. Connect to a microcontroller ADC input.

G
Ground

Common 0 V reference shared with the controller.

+
Supply voltage

Manufacturer range is 3–5 V. Use 5 V with the RedBoard or AVR-MT128.

D0
Digital threshold output

Comparator result based on the potentiometer setting.

Adjustment

Blue potentiometer

Sets only the LM393 digital threshold. It does not change the Hall element’s analog sensitivity or amplify A0.

Indicators

Two LEDs

One LED indicates module power. The other follows the comparator/threshold state.

Measurement

Analog behavior

At rest A0 is typically near half the supply. A magnetic pole moves voltage above or below that baseline. Which direction increases depends on pole and sensor-face orientation, so calibrate using your actual magnet.

Applications

What it can detect

Magnet proximity, shaft speed, wheel position, door/limit position, polarity changes, and relative magnetic-field variation.

RedBoard example

Read both outputs

This prints the raw ADC reading, calculated voltage, and threshold state. Record the no-magnet baseline before interpreting field direction.

const uint8_t hallAnalogPin = A0;
const uint8_t hallDigitalPin = 3;

void setup() {
  pinMode(hallDigitalPin, INPUT);
  Serial.begin(9600);
}

void loop() {
  int rawField = analogRead(hallAnalogPin);
  float voltage = rawField * (5.0f / 1023.0f);
  bool thresholdReached = digitalRead(hallDigitalPin) == HIGH;

  Serial.print("Hall ADC: ");
  Serial.print(rawField);
  Serial.print("  voltage: ");
  Serial.print(voltage, 3);
  Serial.print(" V  threshold: ");
  Serial.println(thresholdReached ? "reached" : "not reached");
  delay(100);
}
Variant warning

“KY-024” is sold by multiple manufacturers. Component choices, digital polarity, and physical pin order may differ. This page follows the pictured Joy-IT SEN-KY024LM module. Read the labels printed on your specific board before wiring it.
